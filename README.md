# Orion Nebula Explorer

The Orion Nebula through eleven telescopes, from backyard astrophotography to
the James Webb Space Telescope, placed on the sky in WorldWide Telescope. Rings
mark 150 proplyds (young stars with planet-forming disks) and diamonds mark 42
JuMBOs (free-floating Jupiter-mass binary objects); select one for a card with
its details and, for 23 proplyds, a Hubble close-up.

This is the 2026 rebuild of the 2023 CosmicDS mini data story
(`minids/Orion-Nebula`, live at web.wwtassets.org/specials/2023/orion-nebula/),
on the same stack as the JWST Image Explorer. The first commit is the untouched
2023 source for reference.

## Stack

Vue 3 + Vue CLI 5, Yarn 4 (`node-modules` linker), Node 22,
`@wwtelescope/engine` 7.40.0 with `engine-pinia` 0.16, `@cosmicds/vue-toolkit` 0.2,
Vuetify 3 (only `<v-app>`), Font Awesome 6 SVG icons, Less. 2D only, so no engine
patches beyond the tile-sharpness one in `src/tile-quality.ts`.

## Commands

```bash
yarn install --immutable
yarn serve          # dev server on http://localhost:8080
yarn lint
yarn typecheck      # vue-tsc
yarn build          # production build into dist/ (no source maps)
yarn check:dist     # fails on .map/.tsbuildinfo in dist or dist over budget
yarn test           # Playwright smoke suite against dist/ (build first)
```

## URL parameters

| Parameter | Effect |
|---|---|
| `?image=<name>` | Open on that image (e.g. `?image=Hubble - Optical`). Kept in sync while browsing; Share copies it. |
| `?markers=proplyds`, `jumbos`, `none` | Which markers start visible (default both). Kept in sync. |
| `?kiosk=1` | Museum mode: no intro, external links become QR codes, idle → attract loop, nightly reload. Replaces the 2023 `Orion-Nebula-Kiosk` fork. |
| `?kioskIdle=<s>` | Kiosk testing override. |
| `?kioskStats=1` | Staff usage-stats panel (anonymous, local to the device). |
| `?tileq=<1..8>` | Override the tile-quality multiplier. |
| `?debug=1` | Install `window.orionApp` for the console. |

Set `VUE_APP_PUBLIC_URL` at build time for the kiosk take-home QR and the
social-preview tags (the deploy workflow sets it to the GitHub Pages URL).

## Data and authoring

- `public/orion.wtml`: `OrionNebula_v10.wtml` (2023) with every URL upgraded to
  https; the 2023 app loaded it over http. `_authoring/` keeps the original and
  the earlier v3/v6 versions.
- `src/data/proplyds.json`, `src/data/jumbos.json`, `public/cutouts/*.webp` are
  generated by `python tools/build_catalogs.py` from the 2023 tables in
  `_authoring/`. Rerun it after changing those tables.
- **Catalog offsets.** The positions are the ones the 2023 app plotted, which
  were nudged to line up with the JWST NIRCam mosaic:
  - JuMBOs (`datamod.py`): RA −0.00023988° (0.86″), Dec +0.0000693° (0.25″),
    from `jumbos_data.csv` → `jumbos_data_2.csv`.
  - Proplyds: RA −0.000219° (0.79″), Dec +0.0000132° (0.05″), from
    `proplyd_data.csv` → `proplyds_data_2.csv` (no script survives for this one).
- **JuMBO columns.** The CSV header is a flattened two-row header. By value the
  columns after DEC are: primary mass (M☉), primary A_V, secondary mass, secondary
  A_V, projected separation (au), tertiary mass, tertiary A_V. JuMBO 24 reads as
  two ~11.5 M_Jup objects 28 au apart, matching Pearson & McCaughrean (2023).
- **Proplyd cutouts.** 30 HST cutouts from ESA/Hubble heic0917 (credit NASA/ESA
  and L. Ricci (ESO), CC BY 4.0). The build matches them to catalog names by
  designation (ignoring a dark-proplyd "d" prefix, an E/W component suffix, and an
  extra Dec digit); 23 match, near-misses are left unmatched.
- `_authoring/baseline-2023/` holds screenshots of the live 2023 site, and
  `tests/fixtures/` the 2023 Places, catalog positions and intro text, used as
  acceptance references.

## Tests

`tests/smoke.spec.ts`: boot with a single starting layer, every fixture Place
selectable (including VISTA, whose apostrophe used to throw), the error card on a
failed catalog load, all 192 markers and their toggles/URL parameter, a JuMBO
card with its masses, deep links, the tour, compare mode, kiosk attract, the stats
panel, an axe scan, and no overlapping panels at phone, landscape and tablet sizes.
